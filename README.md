
 # 🥗 Landing Page - Nutricionista

Uma landing page moderna e responsiva desenvolvida para um nutricionista, com foco em conversão, apresentação profissional e experiência do usuário.

---

## 🚀 Demonstração

🔗 **Acesse o projeto online:**
👉  https://luizgus12.github.io/Dr-marcos-nutricionista-landing-page/  

---

## 🎯 Objetivo

O objetivo deste projeto é simular uma landing page profissional para um nutricionista, destacando:

* Apresentação pessoal
* Especialidades
* Cálculo de IMC interativo
* Formulário de contato
* Experiência visual moderna com animações

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla)
* Font Awesome (ícones)

---

## 💻 Funcionalidades

✔️ Menu mobile com animação
✔️ Animações ao scroll (efeito suave)
✔️ Seção "Sobre" com apresentação profissional
✔️ Cards de especialidades
✔️ Calculadora de IMC com resultado dinâmico
✔️ Exibição de resultados com animação sequencial
✔️ Scroll automático para seções
✔️ Formulário de contato
✔️ Integração com WhatsApp
✔️ Design responsivo (mobile-first)

---

## 🎨 Layout e Design

* Interface limpa e moderna
* Uso de cores suaves e profissionais
* Foco em legibilidade e UX
* Animações para melhorar a experiência do usuário
